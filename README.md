## 📖 Sobre o projeto

O **AutoPlay** é um site desenvolvido para representar um centro automotivo.

A proposta do projeto é criar uma interface moderna e organizada para apresentar os serviços da oficina, informações de contato, horário de atendimento e facilitar o acesso do cliente ao agendamento de serviços.

Além do desenvolvimento do site, o projeto também está sendo utilizado para colocar em prática os conhecimentos adquiridos durante meus estudos de desenvolvimento web.

> 🚧 **O projeto ainda está em desenvolvimento e continuará recebendo melhorias.**
